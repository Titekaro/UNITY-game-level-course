# 🪐 The Silent Planet — Personal VR Project
## Project overview
- **Type:** Personal project / game prototype
- **Purpose:** To design and prototype gameplay and interaction systems in Unity
- **Audience:** Players interested in exploration-based experiences focused on storytelling and problem-solving.
- **Engine:** Unity
- **Focus:** Gameplay systems, interaction, exploration

The Silent Planet is a **personal game concept** developed alongside my XR training, as a way to apply and consolidate my Unity and real-time development skills.
The player crashed on an abandoned planet of an ancient colony destroyed by a long-forgotten war. Most of the planet’s technologies are inactive or broken. The player must explore, understand and progressively rebuild these systems in order to reactivate a portal and return home.

### Key features
- Exploration-driven gameplay
- Environmental storytelling
- Progressive activation of in-game systems
- Modular interaction logic

### Concept & gameplay intentions
The main idea behind the project is to create an exploration experience, centered around:
- Discovery through the environment
- Reconstruction of broken alien technologies
- Problem-solving driven by gameplay constraints

As the player progresses, rebuilt systems unlock new mechanics and areas, gradually restoring fragments of the planet’s past and enabling forward progression.

## Development goals
This project serves as a learning and experimentation ground, with a focus on:
- Implementing gameplay and interaction systems in Unity
- Structuring reusable and modular code
- Applying performance-aware decisions early in development

## Project status
**_In development_**

The Silent Planet is a solo project, developed in parallel with my XR training and coursework. As such, some elements are still **work in progress** and subject to further refinement.
